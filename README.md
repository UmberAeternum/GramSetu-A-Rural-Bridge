# GramSetu - A Rural Bridge

Starter project files added to make the repository show common student project languages (Python, JavaScript) and include standard metadata.

What I added:
- src/main.py — minimal Python entrypoint
- scripts/app.js — minimal JavaScript file
- tests/test_main.py — minimal test using pytest
- README.md — project description and how to run the placeholder
- LICENSE — MIT license
- .gitignore — ignores common Python and Node artifacts
- requirements.txt — lists pytest as a dev dependency

These are small, non-invasive starter files. Add your real project code under src/ and update requirements.txt when ready.
